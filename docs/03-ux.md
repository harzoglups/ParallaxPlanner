# UX — navigation and screens

## Guiding principle: progressive disclosure

There is **no "simple / advanced" toggle on the main screen**. Advanced mode is a switch in the preferences that **adds** elements without changing anything that already exists:

| | Simple mode (default) | Advanced mode |
|---|---|---|
| Navigation | 1 screen + ⚙ icon | Bottom bar: **Calc · Matches · Settings** |
| Quick calc | Min / Max → result | Same + collapsible "Detailed targets" section + "Save as stage" button |
| Matches | hidden | Matches tab → Match → Stage |

The quick calc screen is **the same component** as the stage screen. A stage is just a named, saved quick calc. This avoids maintaining two UIs, and the user learns a single screen.

## 1. Onboarding (first launch only)

```
┌─────────────────────────────┐
│  Welcome                    │
│                             │
│  Language    [English    ▾] │  ← prefilled (detection)
│  Distances   [ m | yd ]     │  ← prefilled
│  Angles      [mrad| MOA]    │  ← prefilled
│  Scope objective            │
│  [ 50 ] mm                  │
│  (see the name: 5-25x56 → 56)│
│                             │
│          [ Get started ]    │
└─────────────────────────────┘
```

A single page. Everything is prefilled: a user in a hurry only has to tap "Get started".

## 2. Quick calc — simple mode

```
┌─────────────────────────────┐
│ Parallax                ⚙   │
├─────────────────────────────┤
│  Min distance    Max distance│
│  [  100  ] m     [  200  ] m │
│                             │
│ ┌─────────────────────────┐ │
│ │   SET TO                │ │
│ │      133 m              │ │  ← very large, the #1 information
│ │   max error 0.02 mrad   │ │
│ │   0.2 cm @100 · 0.4 cm @200│
│ └─────────────────────────┘ │
│                             │
│ Eye position                │
│ [Excellent│●Good │Worst case]│  ← segmented control (F-31), "Good" selected
│                             │
│ ▸ Compare with my setting   │  ← collapsible (F-06)
│                             │
│ ⓘ Objective 50 mm           │  ← scope assumption reminder, tap → Settings
└─────────────────────────────┘
```

Rules:
- Numeric keyboard; the max field gets focus after input in min ("next" button).
- The result updates live. While the fields are empty, a waiting state says "Enter a range".
- The assumptions line is always visible: a result without its D is meaningless.
- **Eye position: segmented control** (3 buttons side by side), not a dropdown. The 3 options are visible at a glance, a single tap is enough (with gloves too), and the effect on the result is visible immediately, which makes the importance of head position clear. The choice is remembered (global preference) and used on every screen. An ⓘ next to the title explains the three levels in one sentence each.

## 3. Quick calc / Stage — advanced mode

```
┌─────────────────────────────┐
│ ← Stage 3 "Barricade"      ⋮│  (in quick calc: "Calc" without ←)
├─────────────────────────────┤
│ ┌─────────────────────────┐ │  ← result card STICKY at the top
│ │ SET TO  60 m            │ │
│ │ ✗ 2 targets off target  │ │
│ │ → 2 suggested settings ▸│ │  (F-55)
│ └─────────────────────────┘ │
│ Targets                 + Add
│ ┌───┬──────┬───────┬───────┐│
│ │T1 │ 25 m │1.0 mrad│✗ 0.58││  ← red row + icon (✓ green, ⚠ orange, ✗ red)
│ │T2 │100 m │1.0 mrad│✓ 0.17││  ← green row
│ │T3 │200 m │0.5 mrad│✗ 0.29││
│ └───┴──────┴───────┴───────┘│
│ Eye position                │
│ [Excellent│ Good │●Worst case]│  (same control, same preference)
│ ▸ Fixed setting             │  (F-56)
│ ▸ Notes                     │
│                             │
│ [ Save as stage ]           │  (quick calc only)
└─────────────────────────────┘
```

Example drawn with "Worst case" selected (values from vector V6). In the "Good" position, these three targets would be green.

Rules:
- **Entering a target**: input happens in a bottom sheet with three fields (distance, size, label). The "Add and next" button keeps the sheet open to enter targets in a row. Tapping a row opens the same sheet to edit the target.
- **Rows are on two lines**, not the four-column table drawn above: the status icon, then the label over "25 m · 1 mrad", then the error with its unit on the right. A table row does not fit once the unit is next to the error, and it breaks with a large system font (NF-08).
- The result card sums the statuses up in one line with its icon: the number of red targets if any, otherwise of orange ones, otherwise "All targets on target".
- Size is optional. A target without size shows its error as neutral (gray), without icon.
- The size unit selector sits next to the field and defaults to the preference. Changing the unit of one target only changes that target.
- Swipe a row → delete (with "Undo").
- Rows are sorted by distance by default. The label lets the user recover the stage order.
- The "2 suggested settings" panel lists: "25 m → T1" then "150 m → T2, T3".
- **Fixed setting** (F-56): a collapsed section with one distance field. Once it holds a valid setting, the card shows "FIXED SETTING 80 m" with "Optimal: 60 m" under it, and the target rows, the status summary and the suggested settings all follow the fixed setting. Emptying the field goes back to the optimal setting. It is the same field as "Compare with my setting" on a range (F-06): one value, the setting the user wants to keep.
- With no target entered, the screen behaves like simple mode (min/max fields visible). As soon as there is a target, the min/max fields are hidden: the range comes from the targets (F-51).

## 4. Matches

```
Match list                     Match
┌─────────────────────────┐    ┌─────────────────────────────┐
│ Matches             +   │    │ ← Rimfire Cup #4         ⋮  │
│ ┌─────────────────────┐ │    │   Dec 14, 2026              │
│ │ Rimfire Cup #4      │ │    │ ┌─────────────────────────┐ │
│ │ Dec 14 · 6 stages   │ │    │ │1 Prone      133 m  ✓    │ │
│ └─────────────────────┘ │    │ │2 Barricade   60 m  ✗ 2  │ │
│ ┌─────────────────────┐ │    │ │3 Tank       100 m  ✓    │ │
│ │ Club practice       │ │    │ └─────────────────────────┘ │
│ └─────────────────────┘ │    │ + Add a stage               │
└─────────────────────────┘    │ ☀ Match mode (screen on)    │
                               └─────────────────────────────┘
```

- In the match list, the "+" of the top bar creates a match: name (required), optional date picked in a calendar, notes. Each match has a ⋮ menu: edit, duplicate, delete (with "Undo"). Dated matches come first, most recent first, then the others by name.
- Tapping a match opens it. Each stage row shows its number, its name, the max error, the setting to dial in large type, and the status icon with the number of red or orange targets ("✗ 2"). A stage with nothing entered yet shows "Empty".
- Each stage has a ⋮ menu: rename, duplicate, move up, move down, delete (with "Undo"). Reordering goes through the menu rather than a long-press drag: it works with gloves and with a screen reader, and needs no drag-and-drop code.
- "Add a stage" proposes the name "Stage N", selected, so one tap saves it and typing replaces it.
- Exporting a match as JSON comes with the import (build step 5).
- **Match mode** keeps the screen on, enlarges fonts and shows each stage's setting in large type. This is the screen used on the firing line.

## 5. Settings

```
General        Language · Theme (auto/light/dark)
Units          Distance · Angles
Scope          Objective diameter (mm)
Assumptions    Eye position: Excellent | Good | Worst case  (same preference as on the result screen)
Advanced mode  [switch]
               └ once on: Target size (mrad | MOA | cm | in)
                          Orange threshold: 50 %  (help: "share of the margin between the center and the edge of the target that parallax may use before the status turns orange; red = parallax alone takes the shot off the target")
About          Short explanation of parallax, formula, disclaimer, version
```

The two settings that only matter with targets (target size unit, orange threshold) sit under the advanced mode switch and appear when it is turned on: progressive disclosure again. Turning the mode off hides them without resetting them.

## Visual rules

- One single hero information per screen: **the setting**.
- Green / orange / red always come with ✓ / ⚠ / ✗ and a text. Material colors or equivalent, with good contrast in both themes, and also different in luminance.
- Digits in a fixed-width font (tabular figures) so that columns stay aligned.
- Units are always displayed next to the number (`133 m`, `0.06 mrad`).
- Number formats follow the locale (decimal comma in French).
