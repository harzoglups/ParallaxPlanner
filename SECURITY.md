# Security policy

## Supported versions

Only the latest release of Parallax Planner receives fixes.

## What the app handles

The app has no account, no server and no network access. Preferences and matches stay in the app's private storage on the phone. A match leaves the phone only when the user exports it as a JSON file and shares it; importing reads a file the user picks, of at most 1 MB.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through the **"Report a vulnerability"** button of the [Security tab](https://github.com/harzoglups/ParallaxPlanner/security). Only the maintainer can read it.

Describe the problem, the app version, the Android version, and the steps or file that reproduce it. You will get an answer as soon as possible; this is a spare-time project, so allow a few days.
